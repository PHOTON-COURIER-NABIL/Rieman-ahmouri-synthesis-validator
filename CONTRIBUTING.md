Contributing
============

Merci pour votre intérêt. Pour contribuer :

- Ouvrez une issue pour proposer un changement ou signaler un bug.
- Créez une branche nommée `feat/...` ou `fix/...` pour vos modifications.
- Ouvrez une Pull Request vers `main` et décrivez les changements.

Tests

- Exécutez `pytest` pour vérifier que tout passe avant d'ouvrir la PR.
